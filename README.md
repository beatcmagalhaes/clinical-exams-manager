# Clinical Exam Manager (Academic Project)

A lightweight desktop application to manage clinical exam records and scheduling, built as an academic project.
It focuses on practical software design for health-related data handling (learning context).

## Features~

- Create, update and manage exam records (CRUD).
- Basic scheduling/date handling (depending on version).
- Local data persistence (e.g., JSON).
- Export functionality (e.g., CSV) when applicable.

## Tech stack

- Python
- Tkinter (GUI)
- JSON / CSV (storage/export)
